# Deploy

This is the Greene Lab Website Template filled with the Microbial Water Quality Lab content.

Create a repository named `huiyunwulab.github.io` (or push these files to the existing `huiyunwu` repository). Enable GitHub Actions. The included workflows build the site and refresh citations from ORCID `0000-0001-8935-7759`.

Pages must be built by Actions, not by the default Jekyll builder. In Settings → Pages, set the source to GitHub Actions if that option is offered.

Placeholder Projects and Blog pages are hidden from the navigation. Example people and example posts were removed.
